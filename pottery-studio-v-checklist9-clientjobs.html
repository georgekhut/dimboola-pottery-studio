Import from Outlook — Acuity Booking Notifications

Open your Acuity booking notification(s) in Outlook and copy the body text. You can paste multiple bookings at once — the app will detect each one automatically and extract name, phone, email, postcode and Acuity ID.

Each block should contain lines like: Name: Jon Fuller   Phone: +61429957208   Email: jonofuller17@gmail.com   post code...: 3424   AcuityID=1700224820

Quick Name Import

One name per line (First Last). Use when you only have names from an Acuity booking list — no contact details will be captured.

Import from Client Jobs Excel Database

Select your Client Jobs spreadsheet (.xlsx). The app expects columns: First Name Last Name Phone Email Post code Type of class and pot items in columns named item 1 through Item 5 (or more).
Each item cell is imported as a pot description. Contact details and pot info are loaded ready for label and checklist printing.

Export & Backup Class Record

Save a permanent record of this class — student details, contact info, pots made, glaze requests. Drop the downloaded file into your Dropbox folder for cloud backup.

Restore from Excel Backup

Load a previously exported class record (.xlsx) back into the app — restores class details, all students, and their pots & glazes. The file must have been exported by this app (sheets: Class Summary, Student Roll, Pots & Glazes).

4 Kiln & Crate Checklist

Prints a full A4 checklist of all students and their pots — with a checkbox to tick off each pot as it's loaded into the kiln crate. Includes a kiln firing notes section. Left margin suits hole-punch filing.

5 Client Name Tags

Prints one name tag per student for the Brother QL-820NWB (62mm DK roll). Shows studio name, full client name, class type, and date — use for apron name badges at the start of class, or for labelling crates and bags on the shelf.

6 Pot Labels

Generates one adhesive label per pot for the Brother QL-820NWB (62mm DK roll). Each label shows student name, class, date, pot description, clay body, glaze, and item numbering.
